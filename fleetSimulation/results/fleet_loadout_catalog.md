- Standard Galaxy: Fleet.get_fleet_ships_available() includes a Mod only when the ship's stored target is all or equals the active galaxy_in.

- The JSON companion retains raw operation names/codes, overrides, upgrade costs, event IDs, level pools, and prerequisite Mod IDs.
