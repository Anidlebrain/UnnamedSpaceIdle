## 本轮排除的陷阱

1. Godot custom_user_dir_name 不能直接填绝对路径；使用进程独立 APPDATA 加相对 TitanResearch，TitanGuard 在 autoload 最前验证实际路径。
2. 空白新档教程把 Engine.time_scale 设为 0.0001；设置教程已读、冻结非战斗 UI 后明确恢复 1。曾经的 30 秒墙钟只推进 0.003 秒，已通过计时校验避免误报。
3. CoreMilestones 的键是 Godot 浮点字符串（如 10.0）。必须调用原版 load_loadout，不能直接把 Python 的 10 键赋给 selected_nodes_for_loadout；否则会使用默认分支。
4. 区域缩放依赖重整状态。合成环境需显式设置 R1Basic/R2Basic/R3Basic/R156Reintegration；缺少前几项会让历史缩放溢出。正式玩家状态不能根据区域偷偷猜填。
5. BOSS 必须走 WaveSpawner.start_wave()。只调用 spawn_colossal_enemy 会漏掉小怪波次，阵列永远无法正常充能。
6. 冻结 UI 时必须保留 AbilityArea 的处理，否则临时技能不会到期。
7. 原版首领死亡会推进区域；研究样本断开这一推进回调，在实际死亡信号上记击杀并结束。
